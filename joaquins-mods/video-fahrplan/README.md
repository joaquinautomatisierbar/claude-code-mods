# Video-Fahrplan
Zeigt über dem Eingabefeld, wo dein aktuelles Video steht: Vorbild, Verpackung, Skript, Teleprompter, Dreh, Schnitt, Feedback, Paket. Der Knopf startet den Schritt mit der passenden Bitte, Erledigt geht weiter. Befehle: /fahrplan <Videoname> startet ein neues Video, /fahrplan weiter, /fahrplan zurück, /fahrplan aus.

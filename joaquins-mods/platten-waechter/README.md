# Platten-Wächter
Zeigt unten in Claude Code, ob die Video-Platten (Personal 1, Business 1) angeschlossen sind und wie viel Platz frei ist. Wird eine Platte getrennt, kommt eine Benachrichtigung. Will Claude eine fehlende Platte anfassen, stoppt der Mod den Befehl und Claude bittet dich, sie einzustecken, statt auf den Mac auszuweichen. Die Plattennamen stehen oben in hooks/register.tsx (DISKS).

# Kontext-Wächter
Ab 70 Prozent vollem Chat (oder 80 Prozent 5-Stunden-Limit) erscheint über dem Eingabefeld ein Hinweis mit dem Knopf Übergabe schreiben. Ein Klick füllt das Eingabefeld mit der Bitte, alles Wichtige in UEBERGABE.md festzuhalten, damit ein neuer Chat nahtlos weitermacht. Bei 85 Prozent kommt zusätzlich eine Benachrichtigung.
